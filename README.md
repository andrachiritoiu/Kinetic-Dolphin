# Mechanical Tulip

## Description

A flower that blooms with a twist of the stem. A mechanical mechanism opens and closes the petals through rotational motion — no electronics, no motors, just pure mechanics.

The tulip is designed from scratch using CAD software. Twisting the stem rotates an inner shaft which pushes the petals outward, causing them to open simultaneously. Releasing the twist allows them to close back. The project explores how rotational motion can be converted into linear motion through a simple threading mechanism, all within a compact and printable form.

---


## Components & Parts

| Part | Role |
|------|------|
| Stem (outer) | The part you twist — acts as the input for the mechanism |
| Inner shaft | Converts rotation into linear (up/down) motion via threading |
| Petals (x5) | Open and close based on the position of the inner shaft |
| Base plate | Holds the mechanism together and acts as a display stand |
| Linkages | Connect the inner shaft to each petal |
